# NiTERRA Frontend V6 - Bandung/Jatinangor Dummy Dataset

Versi ini sama dengan V6 refined UI, tetapi tombol `Load Dummy Data` sudah memakai dataset dummy Bandung Raya/Jatinangor.

Cara jalanin:
1. Buka folder ini di VSCode.
2. Buka `index.html`.
3. Klik kanan -> Open with Live Server.
4. Klik Load Dummy Data, lalu Run Analysis.

Catatan: dataset dummy/simulasi, bukan data eksplorasi asli dan bukan data ANTAM.
